MongoDB Compare

Compare MongoDB databases with ease - detect inserted, updated, and deleted documents across collections

1

Start the Application

Run MongoDB Compare using Docker Compose to get started quickly.

  • Ensure Docker and Docker Compose are installed
  • Navigate to the project directory
  • Run docker-compose up -d to start all services
  • Wait for containers to be ready (30-60 seconds)
  • Access the UI at http://localhost:80
2

Navigate the Dashboard

The dashboard provides an intuitive interface for database comparison.

  • Header: Application title and navigation
  • Connection Form: Enter MongoDB connection strings
  • Database Selector: Choose source and target databases
  • Collection Selector: Select collections to compare
  • Settings: Configure comparison options
3

Configure Connection

Set up your MongoDB connections for comparison.

  • Enter Source Connection String: mongodb://localhost:27017
  • Enter Target Connection String: mongodb://localhost:27017
  • For Docker deployments: mongodb://mongo:27017
  • Click "Test Connection" to verify connectivity
4

Select Databases & Collections

Choose which databases and collections to compare.

  • Select Source Database from the dropdown
  • Select Target Database (can be same as source)
  • Choose collections to compare from the list
  • Multiple collections can be selected for batch comparison
  • Identifier Field: Usually _id or custom unique field
5

Run Comparison

Execute the comparison and view results.

  • Click "Run Comparison" button
  • Wait for comparison to complete (depends on collection size)
  • View summary: Created, Updated, Deleted counts
  • Expand details to see specific document differences
  • Use sample limit to control result size
6

Interpret Results

Understand the comparison results and take action.

  • Created: Documents in target but not in source
  • Updated: Documents with different field values
  • Deleted: Documents in source but not in target
  • Click "View Details" to see field-level differences
  • Export results for documentation or reporting

API Endpoints

The application provides a REST API for programmatic access

POST /api/test-connection Test MongoDB connection string validity
{ "connection_string": "mongodb://localhost:27017" }
POST /api/get-databases List all databases on the MongoDB server
{ "connection_string": "mongodb://localhost:27017" }
POST /api/get-collections List collections in a specific database
{ "connection_string": "mongodb://localhost:27017", "database": "test" }
POST /api/run-comparison Compare collections between databases
{ "source_connection_string": "...", "target_connection_string": "...", "database": "sourcedb", "target_database": "targetdb", "collections": ["users"], "identifier_field": "_id" }
